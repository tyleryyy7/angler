# QMT 内置策略测试成果总结

> 测试日期：2026-09-12（周六）
> 环境：国金证券 QMT 交易端（大QMT，内置 Python）
> 标的：600519.SH（贵州茅台）、600580.SH（测试下单用）

---

## 一、背景

原计划路线：外部 Python 脚本 + MiniQMT（xtquant）实现全自动交易。
9 月 11 日监管新规（两协会《证券公司交易信息系统接入管理规范（试行）》）出台，
多家券商收紧个人程序化交易接入。调查显示：

- **国金证券 7 月 6 日起新开通的 QMT 权限默认不含 MiniQMT**
  （因 miniQMT 架构存在被界定为"类外接"的风险），存量用户后续也可能停用
- 登录报错 "client disconnected" 的原因即权限不含 miniQMT
- 大 QMT（内置 Python 策略编辑器）不受影响，可正常登录
- 被禁的是"类外接"（文件交互下单、模拟点击、反采），官方通道及纯数据读取不受影响

**结论**：路线切换为"大QMT 内置策略 + 人工投喂信号"的半自动架构。

## 三、测试时间线与成果

### 3.1 数据链路验证 ✓
- `get_history_data(60, '1d', field, code)` 取数成功，原生 dict 返回
- 提前补充日线数据后（2026-01-01 ~ 2026-09-12），回测正常推进

### 3.2 费雪变换数学验证 ✓
- 独立实现费雪变换（0.33/0.67 系数、±0.999 截断、全窗口重算防状态漂移）
- 数值行为健康：fish ∈ [-1.38, +3.46]，有界、动量跟踪正确、拐点滞后符合理论
- **发现并修复 prev off-by-one bug**：prev 捕获位置在 fish 更新之前，导致 prev 滞后 2 根 bar，
  同一上穿会连续触发两次（实盘中会导致重复买入）。修复后铁律成立：`当前行.fish == 下一行.prev`

### 3.3 信号统计（600519.SH 日线，2026 年内）
- 7 次零轴上穿，零重复触发：[335] [353] [379] [390] [429] [454] [493]
- 后验质量约五五开：好信号（[353]→+11%、[454]→+14%）与失败信号（[429]→-8%）并存
- **结论**：裸费雪上穿不构成优势，Context 层（人工挑选）是过滤 [429] 类信号的关键——
  分层设计的正确性获得量化支持
- 边界情况：[454] fish 显示 0.000 实为微小正数，贴零穿越动量极弱，
  后续可考虑最小阈值过滤（如 fish > 0.1）

### 3.4 执行链路验证 ✓（含下单）
- `passorder` 参数结构一次通过（23=买/24=卖，1101=按股数，价格类型 5=市价）
- 持仓状态管理正确，信号与成交严格一一对应
- 回测统计：开仓 4 次 = 4 次 BUY，平仓 4 次，无重复无遗漏

### 3.5 含下单回测（600580.SH，单边下跌票 48→27）
- 胜率 25%（4 笔赢 1 笔），**策略净值 0.999 vs 基准净值 0.559**
- 形态解读：典型趋势跟踪特征——多数信号小亏，但费雪下穿清仓规则使大部分时间空仓，
  躲过了 -44% 的主跌段
- 单笔结构问题：赢的那笔只赚 +2.2%（fish 曾冲 2.515），零轴离场回吐过大——
  印证失效点离场规则的必要性（零轴是占位规则，非真实失效点）
- **注意：4 笔样本不构成统计结论**

## 四、架构结论

### 4.1 验证体系分两段
```
信号引擎（策略本体）→ 回测场所：外部 Python + 通达信历史数据
  验证对象：Context/Setup/Trigger 规则的历史表现（此前信号成功率统计即雏形）

执行引擎（QMT 内置）→ 回测场所：QMT 回测模式
  验证对象：信号→下单→持仓→离场 机械链路（9/12 已验完）

接口：信号文件（FileIO 已验证可用）或 handle_input 手动输入
```

### 4.2 策略分层定位（不变）
- Context 层（大盘环境、板块）：人工挑选环节，不代码化，是系统护城河
- Setup 层（Fib/AVWAP、RSI/MACD、CMF）：外部系统 + 人工判断
- Trigger 层（费雪上穿）：可在内置环境实现，与外部系统双实现互证
- 失效点离场：必须在 QMT 侧自动执行（持仓中无人工干预余地）

### 4.3 本次测试未覆盖（明确边界）
- Context/Setup 层（刻意不在内置环境）
- 真实失效点离场（测试用零轴占位）
- 仓位权重规则（测试固定 100 股）
- 多周期共振（测试为单一日线窗口）
- 分钟级数据与盘中执行（滑点、bar 对齐）
